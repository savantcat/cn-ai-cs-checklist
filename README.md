# 中国 AI 客服国标自查清单（GB/T 47746—2026）

面向小微企业的 AI 客服人机协同**自查清单**，逐条对照国家标准 **GB/T 47746—2026《顾客联络服务 人工与智能客户服务协同要求》**整理。

> 一句话：**条款号能对、原文能查、口径能复算、版本能追、边界敢写。**

## 这是什么

- **61 项**可逐条打勾的自查项 = **48 项「应」**（标准要求必须做到）+ **4 项「宜」** + **9 项「可」**
- 其中 **5 项「一票项」**：任一项不满足即视为不达标（对应 5.2.2.6 a)–e) 五类自动转人工场景）
- **覆盖 GB/T 47746—2026 第 4~9 章全部 31 个条款**（5.2.2.6 按 a)–e) 细分 → 35 个可检查节点）
- 每一项都带：**条款号 + 标准原文摘录 + 实施建议 + 是否一票项**

## 数据文件

字段说明（JSON `items[]`）：`id`（编号）/ `clause`（条款号）/ `level`（应·宜·可）/ `is_veto`（是否一票项）/ `requirement`（检查项）/ `how_to_fix`（实施建议）/ `standard_excerpt`（标准原文摘录）。

## 核查方式（可复算）

1. 以标准正式文本为底本（15 页，含第 1~9 章正文）；
2. 按 31 个条款标题定位切分正文 → 拆出要点；
3. 每条要点与检查项做原文匹配，等级按**操作性动词所在句**的「应/宜/可」判定；
4. 结果：条款 **100% 覆盖**；核查中修正过 **2 条漏覆盖条款**（5.2.3.2、5.2.3.3）与 **5 项等级误判**（5.2.3.1、7.1.1×2、7.1.2×2 实为「可」）。

详见 `docs/标准条款清单.json`，可自行复核。
